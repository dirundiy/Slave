# slaveaway.

A quiet late-night study timer: a Pomodoro timer in the middle of the page, plus a weekly planner.

## Run it

```powershell
npm install
npm run dev
```

Then open http://127.0.0.1:5173.

## What's here

- **timer:** focus, short break and long break, with adjustable lengths and an optional chime. Finished focus sessions are logged.
- **planner:** tasks for each day of the week, plus your study time and streak.

Everything is saved in this browser.

## Parked

The Spotify CD player and the AI study tutor were taken out of the app. Their code is kept in `parked/` (not built) in case you want them back.
