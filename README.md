# slave

A quiet late-night study timer: a Pomodoro timer laid out as a lap of Monaco, plus a weekly planner.

## Run it

```powershell
npm install
npm run dev
```

Then open http://127.0.0.1:5173.

## What's here

- **timer:** focus, short break and long break, with adjustable lengths and an optional chime. Each session is a lap of Monaco that ends at the checkered flag, with Oscar Piastri cheering beside the clock.
- **planner:** tasks for each day of the week, plus your study time and streak. Everything saves in this browser, and you can download a backup file.

## Parked

Older features are kept in `parked/` (not built) in case you want them back: the Spotify CD player, the AI study tutor, and the people chat.
